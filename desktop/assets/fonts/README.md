# Fonts

## Fira Code

The interface font of Game Save.

| File | What it is |
|---|---|
| `FiraCodeNerdFontPropo-Medium.ttf` | the proportional face, for the titles and the labels |
| `FiraCodeNerdFontPropo-SemiBold.ttf` | the same, for the text that has to stand out |
| `FiraCodeNerdFontMono-Medium.ttf` | the monospaced face, for the paths and the fields |

project (release v3.5.1, <https://github.com/ryanoasis/nerd-fonts>), which add
the icons of a lot of tools.
